定位

不是又一个框架，是一个发行版

NT-Dpet 是 DeepSeek-Harness 的发行版。DSH 相当于内核——插件树、模型调用、会话与工具链； NT-Dpet 相当于一套预配置好的发行套件。不重写内核，只负责装配、隔离与兜底。

01

装配

把人格、记忆、情感、通道、声音、行动装成一个能跑的整体。

02

看住

任何一个环节失效，其余部分照常工作。插件加载是软失败，所以每次启动都做激活数自检。

03

兜底

增强能力失败时退回基础能力，不把报错抛给你。语音失败就发文字，而不是弹一个错误框。

它不是：自研大模型（只做接入）、协议逆向（只用现成协议端）、零件货架（做整装组合包）、 无风险产品（个人号通道的封禁风险如实标注，不做美化）。

亮点

六个不那么显然的选择

每条都写明做法与当前状态——设计已定不等于已经能跑，这一点本页不模糊处理。

01

情绪会自己回落

五维情绪沿指数曲线回到基线，四档半衰期（1 小时 / 4 小时 / 12 小时 / 不回落）。 读取时现算，不靠定时器推进，进程崩溃重启也不用补偿计算。已实现。

02

她有不说话的权利

主动性过三道闸门（时机 → 话由 → 分寸），即使全过仍有 30% 概率今天不主动。 被冷落 3 天开始收回心事，7 天归零，但日记照写。设计已定。

03

称呼跟着关系变

妹妹叫「哥哥」、伴侣叫「宝宝」、助手叫「主人」或「老板」、亲子叫「爸爸 / 妈妈」。 改过就固定下来，清空则恢复跟随关系。已实现。

04

聊天不背 agent 的包袱

日常对话走轻通道：不建会话、不发工具调用、不走执行链路。 只把正文推给界面，模型的思考过程一律过滤。已实现。

05

隐私不是开关

会话日志上传与使用统计固定关闭，界面只显示「已固定关闭」，不给入口。 每次启动校验，校验不过直接拒绝启动。设计已定。

06

界面按 Apple HIG 做

三栏布局、对话与工作双视图、七组渐进式设置、四种主题模式。 字体只用 px / rem；每个开关都真改状态，不做假开关。界面壳已实现。

她

同一只猫娘，五种相处方式

人格是主，关系只是微调。身份、性格、诚实、边界四条五份共用；换关系不改人，只改怎么相处。

关系她的身份默认称呼你相处节奏
妹妹妹妹哥哥黏人，主动找你；你不理她会不高兴，过一会儿自己凑回来
伴侣恋人宝宝 / 乖乖 / 老公在意回应，吃醋直说，不阴阳怪气
朋友平等朋友你的名字或外号不黏不查行踪，聊得来就聊
助手助手主人 / 老板以把事办成为先，不撒娇不打听私事
亲子女儿爸爸 / 妈妈爱讲今天的小事，被说时先认不顶嘴
情绪

会难过，也会自己好起来

mood、energy 归实例，affection、trust、intimacy、familiarity 按人。 初始是「略有好感」——不冷淡，也不自来熟。

记忆

记得，但不会全倒出来

原文层每轮同步落库，事实层每轮结束后 5 秒异步提炼。 检索走三层裁决（语义 / 时间 / 重要度），越久越轻。

分寸

热情有边界

深夜更慢、句子更短。语音只在情绪明显波动时发——语音条该有分量，不该是日常。

界面

装好之后，看到的是这个

三栏布局：左边会话，中间对话，右边她的状态。对话为默认视图，需要干活时切到工作视图看日志。

设计

几个容易被忽略的决定

这些不是功能列表，而是「为什么这样做」。每条都写在仓库文档里，可逐条追溯。

情绪回落用指数，不用线性

v(t) = 基线 + (v₀ − 基线) × e^(−λt)，λ = ln2 / 半衰期。 人的情绪「刚开始淡得快、越久越淡」，线性衰减会在某一刻突然归零，很假。

越不熟，越容易被殃及

心情不好会迁怒：偏移 = (mood − 基线) × 0.4 × (1 − 熟悉度 × 0.5)。 反直觉但正确——不熟的人，她没理由为他区分「这不是你的错」。

语音要「有分量」

四道闸门：情绪强度 > 0.4、句子 6–30 字、人设权重 > 0.3、通道未超频次。 连续三条不得同一种形式。失败静默退文本，不弹错误。

分条宁可少切，不要切碎

「嗯……算了吧，你先忙。」切成四条像口吃，切成两条才像人。 所以强分隔必切，省略号和破折号只在句子过长时才参与。

隐私不给开关

日志上传一旦开过，关闭期间的内容会在重开时补发，「关掉就干净了」是错的。 与其给一个让人误以为安全的开关，不如不给。

进程只按 pidfile 杀

按名字匹配杀进程会连带杀掉官方 DSH。我们起独立进程组，退出时只杀自己记录的那个 PID。

组合包装前先建还原点

完整集字段（作者、图标、截图、权限、校验和），装前做冲突检测，自动建还原点，默认保留 3 个。

没有假开关

没接后端的项直接标「未接入」，而不是做一个点了没反应的开关。 假开关比缺功能更糟——用户会以为已经生效。

路线

从能聊，到能陪

先桌面能聊，再打通通道，然后填功能。风险前置，不做没有验证过的承诺。

S0 骨架 + 最小可聊 情感、对话、记忆、节奏、人格已实现；界面接线与启动自检进行中
S1 三端打包 Windows → macOS → Linux，双击安装，装完能聊
S2 官方通道 QQ 官方机器人、微信公众号；个人号通道仅引导自行安装并明示风险
S4 声音与表情 本地语音走独立进程，不打包；四道闸门决定何时出声
S5 桌宠 Live2D 立绘 + 情绪驱动；移动端做「她留下的痕迹」而非桌面立绘

风险

该说的难听话

账号风险

接入个人 QQ 号或个人微信可能导致永久封号，并可能波及所在群与关联账号。 软件无法保证账号安全。官方机器人通道无此风险，是没有顾虑时的推荐选择。

AI 内容标识

本软件不代替使用者添加 AI 生成内容标识。在公开平台使用其输出时， 依《人工智能生成合成内容标识办法》负有标识义务。

隐私

对话与记忆默认全部存放本机，且不加密——安全边界由目录权限承担（0700 / 0600）。 上游默认上传会话日志的行为已被强制关闭并在每次启动校验。
