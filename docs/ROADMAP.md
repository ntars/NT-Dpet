# 开发清单（至可交付上线）

> 本文是可执行清单，不是路线图摘要。每一项均含：改动位置、验收标准、依赖关系。
> 定时任务按顺序取第一项未完成者执行，完成后勾选并记录提交号。
> 里程碑编号 M0–M8，任务编号 M<里程碑>.<序号>，子步编号 M<里程碑>.<序号>.<子序>。

## 执行约定

1. **一次只做一项**：定时任务每次只推进一个未勾选任务，避免半成品堆积。
2. **不通过不提交**：单测或构建失败即回退该次改动，任务标记为「阻塞」并写明原因。
3. **不触碰边界**：不写 `~/.dsh`、`~/.agents`；不修改 `index.html` 以外的个人文件；不做删除类操作。
4. **不擅自改版本**：里程碑内不升版本号，仅在里程碑收口时升一次并打 tag。
5. **声明同步**：任何新依赖在引入的同一次提交内更新 `NOTICE`、`docs/CREDITS.md`、`docs/ADOPTION-REGISTER.md`。

  - 方案 A（可注册）：在 `packages/ui` 内新增 `src/server.ts`，暴露 `/api/ntdpet/*`。
  - 方案 B（不可注册）：新增独立本地服务 `packages/ui/server/`，监听 `NTDPET_API_PORT`（默认 9061），仅绑 `127.0.0.1`。
