      开发者

      这些开关会改变软件的行为方式，普通使用不需要碰。

      开发者模式 开启后可见代码级日志、可加载第三方插件、可执行构建脚本。 开启时自动创建还原点。

      开启开发者模式意味着三件事

      • 你能看到完整代码运行记录，包括对话原文与账号标识
      • 第三方插件可以读写本机文件，我们无法审查每一个
      • 插件附带的构建脚本会被实际执行

      开启后会自动创建还原点，出问题可一键退回。

      还原点 最近一次：安装时自动创建
      插件来源 只从自有市场安装，第三方来源需手动添加
      仅自有市场

      开发者模式的两条保护是同时生效的：必须先看到警告并确认，开启后立刻有还原点。 只做其中一条等于没做。
