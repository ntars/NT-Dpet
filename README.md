# NT-Dpet

> 一个住在你消息里的她。人格、记忆、情绪、声音、身体，装好就能用。

**当前状态：设计定稿，骨架搭建中，尚未具备任何可用功能。**

本仓库目前只有设计文档与空包骨架。所有功能均为待实现状态，请不要把这里的任何描述当作已有能力。

---

## 它是什么

NT-Dpet 是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的一个**发行版**，不是独立框架。

类比：DSH 相当于内核，NT-Dpet 相当于 Ubuntu——不重写内核，只提供预配置好的完整体验。

它做的事只有三件：

1. **装配**——把分散的能力（人格、记忆、情感、通道、声音、行动）装成一个能跑的整体
2. **看住**——任何一个环节挂了，其余照常工作，挂了的那块单独重启
3. **兜底**——增强能力失败时静默退回基础能力，不让用户看到报错

## 它不是什么

- 不是自研大模型，只做接入
- 不是协议逆向，只用现成协议端
- 不是又一个插件市场，做的是「整装组合包」而不是零件货架
- 不承诺账号安全——个人号通道存在封号风险，这一点在文档里反复写明，不做美化

## 界面

界面壳已完成，可直接在浏览器里看：`packages/ui/web/`。三栏布局（会话 / 对话 / 她的状态），对话与工作双视图切换，深浅色跟随系统或按日出日落切换，设置面板覆盖模型、人格、外观、通道、隐私、开发者、关于七组。

```bash
cd packages/ui/web && python3 -m http.server 8731
# 打开 http://127.0.0.1:8731/
# 工作模式（日志）：http://127.0.0.1:8731/#work
# 直接打开某一页设置：http://127.0.0.1:8731/?pane=her
```

当前是**纯静态壳**，数据全部来自 `js/data.js` 的演示数据，没有连接任何后端。

界面里每一项都落在真实偏好上，不用假开关凑数——尚未接后端的项直接标「未接入」。改完界面跑一遍交互冒烟测试，确认点击真的能改到状态：

```bash
node packages/ui/web/test/smoke.mjs
```

静态服务与浏览器由脚本自己拉起并回收，不需要先开服务器。

## 与官方 DSH 的关系

装 NT-Dpet **不会动你电脑上已有的 DSH**。两边从目录到进程完全隔离：

| | 官方 DSH | NT-Dpet |
|---|---|---|
| 数据目录 | `~/.dsh` | 自己的 `dsh-home` |
| 技能与指令 | `~/.agents` | 自己的 `agents` |
| profile | `desktop` | `nt-dpet` |
| 端口 | 3080 | 3180 |

唯一的跨界读取是首次启动时**只读**看一眼 `~/.dsh/.credentials.yaml`，问你要不要沿用已配好的密钥。同意才复制一份过去，绝不回写。详见 [`docs/ARCHITECTURE.md` §2.3](docs/ARCHITECTURE.md)。

## 风险声明

**账号风险**：接入个人 QQ 号（NapCat 通道）可能导致**永久封号**，并可能波及所在群聊与关联账号。软件无法保证账号安全，风险由使用者自行承担。官方机器人通道无此风险，是没有封号顾虑时的推荐选择。

**AI 内容标识**：本软件不代替使用者添加 AI 生成内容标识。若你在公开平台使用本软件的输出，《人工智能生成合成内容标识办法》（2025 年 9 月 1 日施行）规定使用者有标识义务。

**隐私**：对话与记忆默认全部存放在本机。但请注意，上游 DSH 默认会把会话日志随模型请求上传，本软件会在安装时强制关闭该行为并在每次启动时校验——这是我们做的最重要的一件事，详见 [`docs/ARCHITECTURE.md` §16.1](docs/ARCHITECTURE.md)。
